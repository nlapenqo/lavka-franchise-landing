# Прототипы лендинга франшизы Яндекс Лавки

Песочница дизайн-концептов для лендинга франшизы Яндекс Лавки — по несколько вариантов вёрстки на каждый блок страницы.

**Демо:** финальный лендинг открывается с корня сайта → [`landing/final.html`](./landing/final.html).

## Структура
- `index.html` — редирект на финальный лендинг
- `landing/final.html` — финальная сборка лендинга
- `blocks/index.html` — галерея всех блоков и версий
- `blocks/<NN>-<имя>/vN.html` — самостоятельные страницы-прототипы блоков (01 меню … 12 футер + изометрия даркстора)
- `blocks/_shared/` — общие дизайн-токены, база стилей, скрипты
- `references/fonts/` — шрифты Yandex Sans (YS Geo / YS Text)

## Статус
Прототипы разных вариантов дизайна. Данные, тексты и визуалы — заглушки (рыба); финальную версию собирают отдельно на основе выбранных концептов.
