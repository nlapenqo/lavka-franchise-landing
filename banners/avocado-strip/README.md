# Performance-баннер «Авокадо Хасс» — бегущая полоса «большие скидки»

Макет: Figma `Kec4yVv3ZhKmIQZY059Vus`, фрейм `1381:21536` (960×720, исправленная полоса 16.09; прежний `1372:20729`).
Появление сцены с теми же таймингами, что в `../petelinka-tag` (авокадо 0–1.75 с, дальше лесенкой логотип, −25%, цена, название, юртекст по 1.4–1.5 с с шагом ~0.15 с), лента выезжает вдоль себя (0.53–2.13 с) и бесконечно едет вправо. Без библиотек, чистый CSS. Клик по баннеру — повтор.

## Как устроено
- `index.html` — баннер целиком, стили внутри. Координаты из макета; порядок слоёв как в Figma
  (зерно фона поверх текста, полоса над зерном, авокадо поверх полосы).
- Полоса: элемент `.strip` с матрицей поворота 4.28° из макета, внутри `.track` — 4 периода
  «большие скидки» (340 px) + «09–22.11» (208 px), период 548 px. Трек едет `translateX(-548px → 0)`
  за 20.5 с, `linear infinite`: узор в начале и в конце совпадает, шва нет. Скорость ≈ 26.7 px/с (16.09: втрое медленнее первой версии, затем ещё на 25%).
- Выезд ленты — `clip-path` на `.strip` от локального x≈560 (левый край кадра) до конца.
- Зерно фона разрезано как в макете: `noise-under.svg` (эллипсы 1880–1882) под лентой, `noise-over.svg` (1883) над ней.
- В макете у каждого сегмента своя оранжевая подложка и половинки звёздочек по краям (обрезаны кадром).
  В HTML — одна подложка на весь трек и целая звёздочка на каждом стыке, чтобы при движении не было
  волосяных швов между сегментами.
- `assets/sparkle.png` — звёздочка, отрендеренная Figma (SVG-фильтр текстуры в браузере зернит сильнее);
  фон канваса Figma убран восстановлением альфы.
- `qa-frames.mjs` — раскадровка (копия из `../avocado-tag`).
