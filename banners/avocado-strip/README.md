# Performance-баннер «Авокадо Хасс» — бегущая полоса «большие скидки»

Макет: Figma `Kec4yVv3ZhKmIQZY059Vus`, фрейм `1372:20729` (960×720), полоса — `1372:20674`.
Появление сцены с теми же таймингами, что в `../petelinka-tag` (авокадо, логотип, −25%, цена, название, юртекст — лесенкой за ~1.1 с), лента выезжает вдоль себя (0.42–1.22 с) и бесконечно едет вправо. Без библиотек, чистый CSS. Клик по баннеру — повтор.

## Как устроено
- `index.html` — баннер целиком, стили внутри. Координаты из макета; порядок слоёв как в Figma
  (зерно фона поверх текста, полоса над зерном, авокадо поверх полосы).
- Полоса: элемент `.strip` с матрицей поворота 4.28° из макета, внутри `.track` — 4 периода
  «большие скидки» (320 px) + «09–22.11» (214 px), период 534 px. Трек едет `translateX(-534px → 0)`
  за 15 с, `linear infinite`: узор в начале и в конце совпадает, шва нет. Скорость ≈ 35.6 px/с (16.09 — втрое медленнее первой версии).
- Выезд ленты — `clip-path` на `.strip` от локального x≈500 (левый край кадра) до конца.
- В макете у каждого сегмента своя оранжевая подложка и половинки звёздочек по краям (обрезаны кадром).
  В HTML — одна подложка на весь трек и целая звёздочка на каждом стыке, чтобы при движении не было
  волосяных швов между сегментами.
- `assets/sparkle.png` — звёздочка, отрендеренная Figma (SVG-фильтр текстуры в браузере зернит сильнее);
  фон канваса Figma убран восстановлением альфы.
- `qa-frames.mjs` — раскадровка (копия из `../avocado-tag`).

## Figma
Копия с анимацией слева от оригинала: «960x720_5сек — анимация (появление + лента)» `1382:1064`, таймлайн 5 с.
Появление — те же тайминги; лента проявляется прозрачностью (выезда через маску в Figma нет) и за 5 с проходит 178 px
с той же скоростью, заканчивая ровно в положении макета. Motion в Figma двигает узел по осям фрейма, а не вдоль поворота,
поэтому сдвиг разложен: `TRANSLATION_X −177.50 → 0`, `TRANSLATION_Y +13.28 → 0`, LINEAR.
Оригинал `1372:20729` возвращён в исходное состояние (первый быстрый луп снят, таймлайн 2 с).
