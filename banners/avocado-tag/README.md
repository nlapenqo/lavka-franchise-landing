# Performance-баннер «Авокадо Хасс» — анимация бирки «большие скидки»

Макет: Figma `Kec4yVv3ZhKmIQZY059Vus`, фрейм `1353:18879` (960×720, страница «РК Большие Скидки»).
Сценарий: пустой фон → бирка «большие скидки» крупно → бирка уменьшается и «клеится» узелком
на черенок авокадо → появляется остальное. Без библиотек, без адаптива: чистые CSS-кейфреймы.

## Файлы
- `index.html` — галерея шести вариантов (iframe ×0.5, «Повторить» перезапускает).
- `v1.html … v6.html` — самостоятельные баннеры; клик по баннеру — повтор. **Генерируются** из `make.mjs`.
- `make.mjs` — единственный источник таймингов: кадры задаются в секундах, скрипт переводит их в проценты
  `@keyframes` (easing на каждом отрезке). Правка → `node make.mjs`.
- `banner.css` — статичная вёрстка по координатам макета (общая для всех вариантов). Подключается с версией `?v=` из `make.mjs`: Pages кэширует CSS на 10 минут, при правке стилей поднимать `VER`.
- `_static.html` — финальный кадр без анимации, для сверки с `assets/reference.png` (экспорт из Figma).
- `qa-frames.mjs` — раскадровка: `node qa-frames.mjs <url> <outdir> 0.5,1.1,1.7` снимает кадры на заданных секундах
  (ставит все CSS-анимации на паузу и выставляет `currentTime`). Локальный сервер: `python3 -m http.server 8821` в корне репо.
- `assets/` — авокадо (png 921², зеркалится через `scaleX(-1)`), svg-слои бирки, логотип, зерно фона; `fonts/` — YS Geo/YS Text.

## Варианты
| # | Название | Механика |
|---|---|---|
| 1 | Планер | появляется крупно → планирует к авокадо, довес поворота −9°→−6°, авокадо «принимает» (scale .985) → лесенка контента |
| 2 | Штамп | висит крупно с мягкой тенью → разгон (ease-in) и удар → авокадо пружинит (scaleX 1.025 / scaleY .965) → контент выскакивает с перелётом |
| 3 | Маятник | ось вращения — узелок (`transform-origin: 253.85px 16.6px`), затухающие качания +6 → −13 → +1 → −11 → −3.5 → −7 → −6; верёвочка и узелок скрыты до полёта: во время полёта штрих вырастает из колечка к черенку (1.35–1.7 с, `stroke-dashoffset` на инлайн-SVG), узелок ставится на посадке с перелётом (1.64–1.84 с) |
| 4 | Заголовок | сначала только белый текст «большие скидки», под него слева выезжает оранжевая бирка (clip-path), затем перелёт |
| 5 | Волна | после посадки всё раскрывается по расстоянию от узелка (задержка = 1.6 с + d/1200), сдвиг 22 px наружу |
| 6 | Фокус | бирка возникает близко к камере не в фокусе (blur 12 → 0), уходит в глубину; авокадо выходит из размытия |

Общие константы: центр бирки в покое (434.65, 175.9), поворот −6°; узелок в покое (569.2, 137.2) — точка «приклейки».
Крупное состояние: scale 2.2–2.6 с центром около (465, 360).

## Figma
Четыре копии фрейма с кейфреймами Motion лежат на той же странице ниже фрейма «БС» (y = 30000):
«Анимация 1 — Планер» `1356:740`, «2 — Штамп» `1356:780`, «3 — Маятник» `1356:820`, «4 — Волна» `1356:860`
(= HTML-варианты 1, 2, 3, 5). Треки: OPACITY, TRANSLATION_X/Y, ROTATION, SCALE_XY (VECTOR); у «Маятника» верёвочка рисуется через PATH_TRIM_START 1 → 0.
Ось «маятника» в Figma всегда центр узла, поэтому вращение вокруг узелка пересчитано:
`T = t + (K−C) − s·R(Δφ)(K−C)`, `ROTATION = −φ_css − 6`. Проверка — `export_video` (480 px, 10 fps) + ffmpeg.
