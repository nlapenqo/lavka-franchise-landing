# Performance-баннер «Классическая бирка» (Петелинка) — появление + бирка дёргается

Макет: Figma `Kec4yVv3ZhKmIQZY059Vus`, фрейм `1372:20848` (960×720). Без вступления с крупной биркой:
всё медленно появляется наложенной лесенкой, бирка проявляется, мягко качнувшись на узелке, и дальше дышит маятником ±2°; звёздочка на цене изредка плавно гаснет.

## Файлы
- `index.html` — галерея пяти вариантов покачивания бирки (iframe ×0.5, «Повторить» перезапускает).
- `v1.html … v5.html` — самостоятельные баннеры. **Генерируются** из `make.mjs`, руками не править.
- `make.mjs` — единственный источник таймингов: появление сцены + пять функций покачивания. Правка → `node make.mjs`.
- `static.css` — статичная вёрстка по координатам макета, `markup.html` — разметка (общие для всех вариантов).
- `qa-frames.mjs` — раскадровка; `--rect ".tag__knot img"` пишет рамку узелка, `--probe` печатает opacity/scale/rotate.

## Появление (одинаковое во всех вариантах)
Тайминги из спокойной версии, умноженные на 1.25 (`K` в `make.mjs`): упаковка 0–1.75 с, дальше лесенкой
логотип, −25%, цена, 239, название, юртекст — по 1.4–1.5 с с шагом ~0.15 с. Бирка проявляется с 1.0 с за 1.25 с.
Звёздочка появляется и раз в 3.2 с плавно гаснет (opacity 0, scale 0.5) и возвращается.

## Пять вариантов покачивания
Угол считается численно: `A(t) = A1 + (A0 − A1)·e^(−t/τ)` умножается на периодическую форму. Бирку «отпускают»
с угла A0, размах гаснет до A1, фаза на стыке с бесконечным циклом совпадает — рывка на переходе нет
(замер: скачок скорости 0.02–0.40 °/с). Ось вращения — узелок, дрейф 0.02 px во всех вариантах.

| # | Название | Форма | Пик 0–6 с | Размах на 4–6 с |
|---|---|---|---|---|
| 1 | Маятник | один синус, период 2.6 с, A0 9° → A1 0.9° | 21°/с | 3.2° |
| 2 | Дыхание | синус, период 7 с, A0 6° → A1 2° | 5.3°/с | 2.8° |
| 3 | Два ветра | 0.78·sin(8.4 с) + 0.22·sin(2.8 с) | 5.2°/с | 3.5° |
| 4 | Порывы | мягко нарастающий порыв каждые 6 с, затухание e^(−t/1.7) | 18°/с | 0.8° |
| 5 | Маятник с порывами | 0.62·порыв + 0.38·sin(3 с) | 12°/с | 2.1° |
