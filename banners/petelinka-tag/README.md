# Performance-баннер «Классическая бирка» (Петелинка) — появление + бирка дёргается

Макет: Figma `Kec4yVv3ZhKmIQZY059Vus`, фрейм `1372:20848` (960×720). Без вступления с крупной биркой:
всё медленно появляется наложенной лесенкой, бирку «отпускают» на узелке, и она качается как маятник, затухая с 5° до 0.9°; звёздочка на цене изредка плавно гаснет.

## Файлы
- `index.html` — **готовый баннер**: выбран вариант «Маятник». Генерируется из `make.mjs`, руками не править.
- `make.mjs` — единственный источник таймингов. `node make.mjs` собирает баннер;
  `node make.mjs --variants` дополнительно кладёт `v1…v5.html` и галерею `variants.html` для сравнения.
- `static.css` — статичная вёрстка по координатам макета (16.09 звёздочка сдвинута по фрейму `1395:1578`: центр 281.96 / 352.72), `markup.html` — разметка и тексты баннера.
- `assets/star.png` — звёздочка, отрендеренная Figma (SVG с фильтром текстуры в браузере зернит); фон канваса снят восстановлением альфы.
- `qa-frames.mjs` — раскадровка; `--rect ".tag__knot img"` пишет рамку узелка, `--probe` печатает opacity/scale/rotate.

## Появление
Тайминги умножены на `K = 1.25` в `make.mjs`: упаковка 0–1.75 с, дальше лесенкой логотип, −30%, цена, 329,
название, юртекст — по 1.4–1.5 с с шагом ~0.15 с. Бирка проявляется с 1.0 с за 1.25 с.
Звёздочка появляется и раз в 3.2 с плавно гаснет (opacity 0, scale 0.5) и возвращается.

## Покачивание бирки — «Маятник»
Угол считается численно: `A(t) = A1 + (A0 − A1)·e^(−t/τ)` умножается на `sin(2π·t / 2.6 с)`.
Бирку «отпускают» с **A0 = 6.5°**, размах гаснет к **A1 = 1.5°** (τ = 2.6 с) и дальше держится еле заметным;
фаза на стыке с бесконечным циклом совпадает, поэтому перехода не видно. Ось вращения — узелок.

Замеры (`qa-frames --probe`, шаг 0.05 с): пик скорости 15.4 °/с, первый максимум +5.4°, размах после 8 с — 1.8°,
дрейф узелка 0.02 px. Углы: 1.5 с +5.3°, 2.5 с −2.0°, 3.0 с −3.8°, 5 с −0.6°.

Остальные четыре варианта (Дыхание, Два ветра, Порывы, Маятник с порывами) остались в `make.mjs`
в массиве `VARIANTS` — собрать и сравнить можно флагом `--variants`.
