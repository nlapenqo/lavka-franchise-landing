# Performance-баннер «Классическая бирка» (Петелинка) — появление + бирка дёргается

Макет: Figma `Kec4yVv3ZhKmIQZY059Vus`, фрейм `1372:20848` (960×720). Без вступления с крупной биркой:
всё медленно появляется наложенной лесенкой, бирка проявляется, мягко качнувшись на узелке, и дальше дышит маятником ±2°; звёздочка на цене изредка плавно гаснет.

## Тайминг (с) — спокойная версия (16.09: «медленно, элегантно, бальяжно»)
| Что | Когда |
|---|---|
| Упаковка: сдвиг 36/12 px + прозрачность, мягкая кривая `--calm` | 0–1.4 |
| Логотип, −25%, 179 ₽, 239, название: подъём 16 px (логотип −8 px) | 0.3–2.1, шаг ~0.12, по 1.1–1.2 с |
| Зачёркивание, 0+ и юртекст | 1.0–2.1 |
| Бирка: проявляется за ~1 с и один раз мягко качается −12° → +3° → −2° | 0.8–3.4 |
| Бирка дышит маятником ±2° вокруг положения макета, синусоида | 3.5 с туда, 3.5 с обратно, с 3.4 |
| Звёздочка: появляется, затем раз в 3.2 с плавно гаснет (opacity 0, scale 0.5) и возвращается | гаснет 0.8 с, возвращается 1 с; с 2.4 |

Замеры (`qa-frames --probe` с шагом 0.05 с): скорость вращения бирки была до 305°/с, стала до 24°/с на вступлении
и до 1.8°/с в дыхании; звёздочка гаснет в 4 раза медленнее, чем в версии с миганием каждые 1.5 с.

## Устройство
- `index.html` — всё в одном файле, стили и кейфреймы внутри. Клик по баннеру — повтор.
- Бирка — кадр 230×96 с матрицей поворота 17.4° из макета. Качание — обёртки `.pivot` на весь баннер
  с `transform-origin` в узелке (555.38, 203.33): вступление и дыхание маятника на двух вложенных обёртках, углы складываются.
- Проверка узелка: `node qa-frames.mjs <url> <out> 0.5,1,2.2 --rect ".tag__knot img"` — центр узелка на всех кадрах
  должен быть (555.38, 203.33); при сдаче дрейф 0.02 px.
- Товар — прямоугольник 500.42×662.80 с поворотом 10.48°, картинка cover.
