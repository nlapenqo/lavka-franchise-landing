# Бизнес-завтрак «Франшиза Яндекс Лавки» — перевёрстка на блоках-конструкторе

Страница `lavka.yandex.ru/about/breakfast-meeting` (Уфа, 28 октября), собранная из универсальных блоков `blocks/` в актуальном стиле сайта франшизы. Первый настоящий лендинг на конструкторе — проверка, что 20 блоков хватает на реальный контент.

- `index.html` — исходник. Стили и скрипт подключены ссылками из `../blocks/` (tokens, base, blocks, blocks.js), шрифты и логотипы — из `../site/`. Локально: `python3 -m http.server 8821` в корне → `http://127.0.0.1:8821/breakfast-meeting/index.html`.
- `preview.html` — самодостаточная сборка (всё внутри): `node blocks/build.mjs --in breakfast-meeting/index.html breakfast-meeting/preview.html`. Не править руками.
- `assets/kv-phone.webp` — телефон с завтраком (на исходной странице фон хиро), обрезан по прозрачности. `video-poster.webp` — постер видео, `og-source.webp` — превью для og:image.
- Прод: https://nlapenqo.github.io/lavka-franchise-landing/breakfast-meeting/

## Правило текста
**Только текст исходной страницы.** Своих формулировок, цифр и обещаний нет. Допустимо: разбить фразу на заголовок и подзаголовок, поправить грамматику, перенести факт из одного места в другое. Необязательные слоты блоков, под которые нет исходного текста, не заполняются.

## Что добавлено в `blocks/blocks.css` этой страницей
- `.hero--split` + `.hero__tag` + `.hero__slot` — хиро в две колонки по левому краю, белая плашка над заголовком.
- `.slot` — заштрихованный слот под кадр со скруглёнными углами и подписью, светлый и на тёмном.
- `.offer__city`, `.offer--compact` — город крупным заголовком вместо чипсов, четыре карточки в ряд; `.cards` с `--n-t` для планшета.
- `.info` (base.css) — подсказка ⓘ с главной, на тач-экранах открывается тапом (blocks.js).
- `.hero__facts` — строка фактов под кнопкой хиро.
- `.step--plain` — шаг «номер + обычный текст».
- `.field select`, `.choices` (base.css) — выпадающий список и пилюли-варианты для форм; `.lead--long` — прилипающий текст у длинной формы; `.section--dark` теперь `overflow:clip`, а не `hidden`, иначе sticky внутри не работает.
- `.map--wide`, `.map__card`, `.map__canvas`, `[data-ymap]` — карта во всю ширину с карточкой поверх и живой Яндекс Картой (загрузчик в blocks.js, зум справа, промо-блок такси скрыт).
- `.footer::before/::after{display:none}` — футер без свечения.
- `.hero__word{white-space:nowrap}` — слово хиро не ломается по дефису.

Блока «Видео» в ките нет: постер с кнопкой и iframe по клику описаны в `<style>` страницы.

На исходнике стоит Яндекс Форма в iframe, её поля со страницы не видны — поэтому взята стандартная форма сайта. Форма никуда не отправляет; подключают разработчики.
