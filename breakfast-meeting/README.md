# Бизнес-завтрак «Франшиза Яндекс Лавки» — перевёрстка на блоках-конструкторе

Страница `lavka.yandex.ru/about/breakfast-meeting` (Уфа, 28 октября), собранная из универсальных блоков `blocks/` в актуальном стиле сайта франшизы. Первый настоящий лендинг на конструкторе — проверка, что 20 блоков хватает на реальный контент.

- `index.html` — исходник. Стили и скрипт подключены ссылками из `../blocks/` (tokens, base, blocks, blocks.js), шрифты и логотипы — из `../site/`. Локально: `python3 -m http.server 8821` в корне → `http://127.0.0.1:8821/breakfast-meeting/index.html`.
- `preview.html` — самодостаточная сборка (всё внутри): `node blocks/build.mjs --in breakfast-meeting/index.html breakfast-meeting/preview.html`. Не править руками.
- `assets/kv-phone.webp` — телефон с завтраком (на исходной странице фон хиро), обрезан по прозрачности. `video-poster.webp` — постер видео, `og-source.webp` — превью для og:image.
- Прод: https://nlapenqo.github.io/lavka-franchise-landing/breakfast-meeting/

## Правило текста
**Только текст исходной страницы.** Своих формулировок, цифр и обещаний нет. Допустимо: разбить фразу на заголовок и подзаголовок, поправить грамматику, перенести факт из одного места в другое. Необязательные слоты блоков, под которые нет исходного текста, не заполняются.

## Правки поверх блоков (кандидаты в `blocks.css`)
- `.hero__frame--phone` — прозрачный PNG выезжает снизу, не кропается.
- `.offer__city` — крупное название вместо чипсов: `min(var(--fs-h1), 14cqi)` при `container-type:inline-size` на карточке; сетка `minmax(0,1fr)`, иначе длинное слово распирает колонку.
- `.video` — постер с кнопкой, iframe подставляется по клику. Блока «Видео» в ките нет.

Поля формы «Имя / Телефон / Почта» и кнопка «Отправить» — служебная заглушка: на исходнике Яндекс Форма в iframe, её поля со страницы не видны. Форма никуда не отправляет; подключают разработчики.
