# Подарочный сертификат в Яндекс Лавку

Макеты под печать для мероприятия (запрос Артёма Салюкова): логотип, лайн
«Сертификат в Яндекс Лавку», номинал, место под промокод. Стиль — лендинг
франшизы: палитра Лавки, YS Geo/YS Text, тёмно-синий фон с градиентными
«пятнами» из hero.

- `index.html` — галерея из 6 вариантов + панель (номинал, промокод, печать).
- `assets/` — логотип: `logo-word.svg` (белый), `logo-word-navy.svg` (тёмный,
  получен из белого заменой `fill="white"`), `logo-mark.svg` (синий знак).
  Оригиналы — `site/assets/figma/`. Шрифты берутся из `site/fonts/`.

## Форматы
Горизонталь 210×148 мм (A5), вертикаль 148×210 мм. Вёрстка в px из расчёта
**4 px = 1 мм** (как в `badge/`): 840×592 и 592×840.

## Варианты
1. **Афиша** — ритм hero: лайн слева, номинал справа, плашка промокода снизу.
2. **Билет** — отрывной корешок с промокодом (перфорация = линия реза).
3. **Светлый** — тот же фон по светлому, номинал синим кругом-стикером.
4. **Мега-номинал** — приём блока «цифры», сумма во всю карточку.
5. **Открытка** — вертикаль по центральной оси, промокод на белой плашке.
6. **Полоса** — светлая вертикаль с пилюлей-навбаром сверху.

## Figma
Файл **«Лавка · Подарочный сертификат»** — `964oZzq6hmmlimOFuT7opW`
(https://www.figma.com/design/964oZzq6hmmlimOFuT7opW), страница «Сертификаты».

- Вёрстка в пунктах: **1 px = 1 pt**, горизонталь 595×420 pt = 210×148 мм,
  вертикаль 420×595 pt. Поэтому PDF из Figma выходит в реальном размере,
  а PNG ×4.17 — это 300 dpi. Оба пресета уже висят на каждом фрейме.
- Пересчёт из HTML: множитель **0,7083** (595 ÷ 840) — кегли, отступы, радиусы.
- Все карточки на авто-лейауте, цвета привязаны к переменным коллекции
  «Лавка · палитра», логотип — компонент с вариантами Цвет=Белый / Тёмный.
- Фон-«пятна» — эллипсы с радиальным градиентом в прозрачность (не блюр):
  вектор, чисто печатается, легко двигать.

## Открыть
`python3 -m http.server` из корня репозитория → `/certificate/`
(через `file://` не заработают шрифты и SVG-логотип).

## Что ещё не финально
- Реальные механика активации, срок действия и юрстрока — плейсхолдеры.
- Вылеты 3 мм и метки реза добавляем в Figma, здесь их нет.
- Кегль номинала автоподгоняется под длину суммы (JS), чтобы «10 000 ₽»
  не ломал композицию.
