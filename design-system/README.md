# Дизайн-система лендингов Лавки · формализация

Источник истины — прод: `site/styles.css` (главная) и `events/prototype.html` (съезд). Всё ниже выведено из них, спорные места решены в пользу гайда по типографике и правил Никиты. Машинная версия — `tokens.json` рядом (DTCG), из неё потом делаются переменные Figma.

## 6 · Движение

Изинги: `ease` cubic-bezier(.22,.61,.36,1) на всё; `ease-drum` (.18,.86,.24,1) барабаны; `ease-slide` (.5,0,.2,1) слайды. Длительности: hover .2s; появление .6s снизу на 28px, стаггер 80 мс; слайд .72s; счётчик 2s. Hover карточки −4px, кнопки −2px. Reduced motion гасит всё.

## 8 · Правила сборки

1. Один экран — одна мысль: заголовок до пяти слов, лид до двух строк, одна голубая кнопка.
2. Тёмное и светлое чередуются; два тёмных подряд — только через полосу.
3. Голубая заливка — только кнопка или таб.
4. Кегли — только из ролей §3, без промежуточных.
5. Цифры крупно, три на блок, голубым на тёмном.
6. Скругление по роли: 32 карточка, 24 медиа, 20 полоса, пилюля кнопка.
7. Фото в скруглённом кадре; нет кадра — заглушка системы, не серый прямоугольник.
8. Движение мягкое, ничего не пружинит.
9. Страница заканчивается действием: форма или панель, потом футер.
10. Новый блок сначала в систему, потом на страницу. Новых цветов, шрифтов, скруглений нет.
