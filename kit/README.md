# kit/ — дизайн-система лендингов Яндекс Лавки (супер-шаблон)

Единый язык для всех страниц франшизы: главный лендинг (`site/`) и страница мероприятий (`events/`) разобраны на **основы + 15 типовых блоков + каркас**. Задача — чтобы коллега с задачей «нужен лендинг» собирал страницу из готовых блоков, а не рисовал с нуля. Следующий этап — перенос в Figma (компоненты, автолейауты, страница-гайд).

## Что внутри
| Файл | Что это |
|---|---|
| `index.html` | Страница кита: обложка с оглавлением, основы F1–F8, блоки 00–16 с подписями «откуда / когда использовать», раздел «Как собирать» (10 правил + 3 рецепта). У каждого блока кнопка **«Копировать HTML»**. |
| `kit.css` | **Единственный файл стилей для лендингов**: токены, база, компоненты, свечение, анимации, блоки, адаптив (≤1199 / ≤1100 / 768–1023 / <768), reduced-motion. Копируется в проект как есть. |
| `kit.js` | Вся интерактивность по data-атрибутам: `data-hdr` (стеклянная шапка), `data-hero` (стаггер слов), `data-rot` (барабан слова), `.reveal`/`data-count` (появление, счётчики), `data-statement`, `data-split` (карусель), `data-reviews`, `data-accordion`, `data-steps`, `data-offers`, `.glow-card`, `data-form` (демо-отправка), `data-burger`/`data-menu`. |
| `kit-chrome.css` | Оформление самой страницы кита (обложка, подписи, образцы). В лендинги не копируется. |
| `template.html` | **Стартовая страница**: шапка + хиро + цифры + текст-медиа + карточки + FAQ + форма + футер. Точка входа для вайб-кодинга: удалить лишнее, докопировать нужное из кита. |
| `build-kit.mjs` | Сборка в один файл (шрифты и картинки base64): `node kit/build-kit.mjs` → `kit-preview.html`; `node kit/build-kit.mjs template.html template-preview.html`; флаг `--artifact` — без html/head/body для claude.ai-артефакта. |
| `kit-preview.html`, `template-preview.html` | Собранные самодостаточные версии — для показа, пересылки, артефакта. Не править руками. |

Ассеты не дублируются: шрифты из `../site/fonts/`, логотипы и иконки из `../site/assets/figma/`, фото из `../site/assets/figma/business/` и `../events/assets/`.

## Как собрать лендинг
1. Скопировать `kit.css`, `kit.js` (и ассеты) или начать с `template.html`.
2. Взять блоки из `index.html` кнопкой «Копировать HTML», расставить в порядке рецепта (обложка кита → «Как собирать»).
3. Проверить: `python3 -m http.server 8821` в корне → `http://127.0.0.1:8821/kit/template.html`; кадры `node tools/shot.mjs <url> <out.png> --w 375|1440 --block .section`.
4. Собрать в один файл: `node kit/build-kit.mjs template.html имя.html`.

## Что не сделано / ограничения
- Мобильный слой — базовый (сетки в колонку, кегли, шапка со знаком и бургером). Пиксельный мобильный макет главного (`site/mobile.css`) не переносился целиком.
- Шаги на десктопе раскрываются по клику; скролл-пин из `site/app.js` в кит не перенесён (страничная механика).
- Форма никуда не отправляет (`data-form` — демо), обработчик — к разработчикам.
