# Супер-шаблон для лендингов · этап 2: переделать HTML-кит по референсу

## Контекст
- Есть `kit/` — дизайн-система лендингов Лавки в HTML: `index.html` (основы F1–F8, блоки 00–16 с подписями и кнопкой «Копировать HTML»), `kit.css`/`kit.js` (единственные файлы, которые копируются в лендинг), `kit-chrome.css` (оформление кита), `template.html` (стартовая страница), `build-kit.mjs` (сборка в один файл, `--artifact` для claude.ai), `README.md`. Превью: https://claude.ai/code/artifact/9671a15f-16a5-4713-a813-1cfe8a3b6e37
- Референс, по которому переделываем: Figma-файл «Untitled» (Drafts Никиты), секция «Скопируй этот шаблон 🙈» — https://www.figma.com/design/aUa80jMIHIGAZJZ4izVJQo/Untitled?node-id=3-70745 . Это копия UI-кита Альфа-Банка «Web :: Site UI-kit Widgets».

- Через Chrome Никиты (инструменты `claude-in-chrome`): веб-Figma спросит аккаунт — выбрать «Nikita · nlapenqo.us@gmail.com · Editor on file»; на экране «Opened in Figma app» нажать «Open here instead». Навигация: клик по слою в панели Layers → Shift+2 (zoom to selection); Return — первый дочерний слой; Tab — следующий слой. Пройти все блоки [D] 1280, «Примерку — [D] 1280», [M] 360 и «Примерку — [M] 360», по скриншоту на блок.
- Если в сессии есть инструменты `plugin:figma:figma` (`get_design_context`, `use_figma`) — файл можно читать через них; перед `use_figma` обязательно загрузить скилл `figma:figma-use`. **В Figma ничего не создавать и не менять** — этот этап только HTML.

## Что в референсе важно (устройство, не внешний вид)
1. Страница — одна колонка инстансов блоков: `Content` → `PageBanner` + `BottomContent` (gap 72 после хиро, 128 между блоками). Собрать лендинг = выбрать блоки и расставить.
2. У блока есть свойства: Device (Desktop/Mobile), Kind (Light/Dark), Preset, тумблеры необязательных частей (Caption, Buttons, BenefitsSlot, TopSlot, VideoBG). Вложенные компоненты со своими свойствами (MainHeaderV3 внутри PageBanner).
3. Слоты с заглушками и правилами: PureCard Block ×1/2/3/4 — заштрихованные карточки с подписью «высота карточки тянется от контента, но не может быть меньше 280px», «заголовок максимум в две строки».
4. Desktop [D] 1280 и Mobile [M] 360 — одинаковый набор блоков, колонки рядом.
5. «Примерка для маркетинга»: header + слоты под ключевые визуалы, названные размером и датой (`1. DB01_KV_558×456_15062026`, `6. DB06_KV_1148×280`, `7. DB07_KV_550×280` ×4), подпись «лишние блоки, которых не будет в итоговом макете, — удалите».
6. Внешний вид референса (System (SF), серо-голубые заглушки, красные кнопки Альфы) не переносить. Язык остаётся наш: токены `kit.css`, YS Geo, синяя гамма, приёмы прод-сайта `site/`.

## Что сделать в HTML (порядок = приоритет)
1. **Паспорт свойств у каждого блока** — как панель Design в Figma. В ките над блоком живые тумблеры: Theme (dark/light), Variant (A/B/C), необязательные части (лид, вторая кнопка, чипсы, подпись, стрелки), число карточек 1–4. Свойства пишутся в разметку (`data-theme`, `data-variant`, `data-slot="caption"`, модификаторы классов), чтобы позже стать пропсами компонентов в Figma 1:1.
2. **Слоты-заглушки, режим «Схема»** — переключатель «Дизайн / Схема» у блока: в схеме контент заменяется заштрихованными заглушками с правилами (мин. высота карточки, макс. строк заголовка, размер кадра), как PureCard в референсе. Заглушка `.ph` из кита — основа.
3. **«Примерка»** — `kit/fitting.html`: шапка + все медиа-слоты шаблона с кодами и размерами (`KV01_hero_1164×560`, `KV02_split_542×480`, `KV03_gallery-wide_3:2`, `KV04_gallery-tall_3:4`, `AV01_88`, `AV02_120`, `LG01_h42`, `OG_1200×630`), чек-лист блоков «убрать лишние», кнопка «Скопировать HTML сборки».
4. **Мобильный вид рядом** — у каждого блока превью 390 (iframe того же блока: `index.html?block=<id>&w=390`, кит умеет показывать один блок без хрома), как колонка [M] 360 в референсе.
5. **Сборщик страницы** («vibe-coding template» из карточки задачи): выбрать блоки, варианты и тумблеры → получить HTML всей страницы одной кнопкой. Минимум: чекбоксы блоков + их панели свойств → «Скопировать HTML сборки» (то же, что в «Примерке»).
6. **Коды и имена**: блоки `LB00…LB16`, варианты `A/B/C`, слоты `KV..`/`AV..`/`LG..` — в подписях кита, в `data-block`, в README.
7. Обновить `kit/README.md` и вступление `kit/index.html`: «Скопируй этот шаблон» — три шага, как в референсе.

## Ограничения
- Только HTML/CSS/JS в `kit/`. `kit.css`/`kit.js` остаются единственными файлами для копирования в лендинг; всё оформление кита — в `kit-chrome.css`.
- Никаких новых цветов, шрифтов и скруглений; язык — прод-сайт `site/`, не брендбук «вообще»; никакого liquid glass.
- Figma пока не трогать — компоненты и страница в Figma будут следующим этапом.
- Проверка: `python3 -m http.server 8821` в корне → `http://127.0.0.1:8821/kit/`; кадры `node tools/shot.mjs <url> <out.png> --w 1440|375 --block .sel`; сборка `node kit/build-kit.mjs` и `node kit/build-kit.mjs index.html <путь> --artifact`; опубликовать артефакт (обновить существующий по URL выше) и прислать ссылку; коммит в `main` без пуша.
