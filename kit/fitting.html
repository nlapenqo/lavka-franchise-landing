Какие картинки готовить, каких блоков не будет и как выглядит HTML собранной страницы. Код слота — это имя файла, размер зашит в имя.

👇 Лишние блоки, которых не будет в итоговом макете, — снимите галочку. У каждого блока — паспорт: вариант, тема, необязательные части, число карточек.

Блоки страницы

Не удалось загрузить блоки из index.html. Откройте страницу через локальный сервер: python3 -m http.server 8821 в корне репозитория → http://127.0.0.1:8821/kit/fitting.html.

Сборка берёт блоки в состоянии из паспортов выше. Порядок — как в ките: шапка, хиро … форма, футер. Пути к картинкам — относительно kit/.
