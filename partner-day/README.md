# День партнёров — блоки «Спикеры» и «Программа»

Макет двух новых блоков для страницы `lavka.yandex.ru/about/franchise/partner_day`.
Файл: [speakers-agenda.html](speakers-agenda.html) — самодостаточный, открывается локально.

Контент — из `Деловая программа__День П.xlsx`, вкладка **«на лендинг»** (спикеры и темы)
и вкладка «Сторилайн конфы» (порядок докладов).

## Композиция (финал, выбор 29.07)

- **«Спикеры» — «Общая сетка»**: все 12 спикеров одной сеткой 6×2 на белом фоне,
  без групповых подзаголовков. Группа — мелкой подписью-кикером в карточке
  («Яндекс» / «Эксперт» / «Франчайзи»).
- **«Программа» — «Компакт»**: таймлайн одной лентой, каждый доклад — одна строка
  «время · тема — спикер». Время обычным текстом без плашек, спикер серым в строке
  темы. Служебные строки (регистрация, перерывы, фуршет) — серым medium.

Отвергнутые варианты обоих блоков остались в сравнивалке `variants.html`
(переключатели, состояние в #hash).

## Фото спикеров

- Формат: квадрат 1:1, минимум 622×620 (как текущая заглушка), радиус `2rem` (`1.8rem` на мобайле).
- Заглушка — `assets/speaker-placeholder.png`, скачана с боевой страницы; фон у неё уже вшит.
- Если фото не на всех — ставить заглушку, сетка не ломается.

## Открытые вопросы

1. **Тайминги в файле пустые** (колонка «время» на вкладке «на лендинг»). В таймлайне стоит
   предварительная сетка 11:00–18:00 (20–30 минут на доклад, два перерыва) — заменить
   на фактическую. Сноску про предварительный тайминг убрали по решению 29.07.
2. **Спикеры без имён** в исходнике: маркетинг («Степан»), горячая еда, AI («Стас Макеев???»),
   Я Смена. В программе стоят как «Спикер Яндекс Лавки» — заменить, когда согласуют.
3. **Статусы из файла:** Петров — нужен ок от пиара; Марова, Бурмистров, Лопатин —
   «переговоры»; Макеев — не подтверждён. Внешние эксперты в файле перечислены как
   альтернативы («Марова; Бурмистров; спикер из Data Insight» и «Газизулин; Ляшевский») —
   в сетке стоят все четверо, лишних убрать после согласования.
4. **Расхождение по фамилии:** вкладка «на лендинг» — Наташа **Крякова**, «Сторилайн конфы» —
   Наташа **Кудрик**. Взята версия с вкладки «на лендинг».
