# Сообщение дизайн-агенту (шаблон)

Заполнить `[...]`, приложить: `TZ-dizajneru.md`, PDF с контентом из `export/`,
шрифты из `_shared/fonts/`, лого из `assets/logo/`, фото из `assets/photos/`.

---

Переделай презентацию «[НАЗВАНИЕ, например: Метрики вместо интуиции]» под
дизайн-систему Яндекс Лавки Франшизы. Полное ТЗ приложено (TZ-dizajneru.md) —
оно главнее любых твоих привычек. Контент бери 1-в-1 из приложенного PDF:
тексты, порядок слайдов и структуру не менять, не сокращать, не дописывать.

Формат: 1920×1080, по фрейму на слайд.

Жёсткие правила (это то, на чём чаще всего ошибаются):

1. Зоны фиксированы на каждом слайде: кикер Y=120, заголовок начинается
   Y=176 (резерв 2 строки — лид всегда на Y=414, даже если заголовок в одну
   строку), контент Y=528–880, колонтитул Y=936. Позиции не зависят от
   количества текста. Проверка: при листании ничего не прыгает.
2. Сетка 12 колонок, поля 120, гуттер 32. Весь текст влево по колонкам —
   в том числе внутри карточек (паддинг карточки 32 = гуттер). По центру —
   только цифра внутри стат-карточки, больше ничего.
3. Шрифт только YS Geo (приложен). Кегли только из шкалы ТЗ:
   240 / 150 / 144 / 112 / 72 / 56 / 40 / 32 / 26 / 20 / 16. Заголовки Black,
   трекинг −1%, интерлиньяж 92%. Заголовок ≤ 2 строк, без точки в конце.
4. Цвета только из палитры ТЗ. База: #1B3A6A (тёмный фон и текст на светлом),
   #00ADFF (акцент: 1–2 слова в заголовке, цифры), #AAD9FC (плашки, линии),
   #F2F7FC (светлый фон), #EAF3FC (карточки). Чёрного и серого текста нет.
   Слайд либо светлый #F2F7FC, либо тёмный #1B3A6A.
5. Логотип — только на обложке и финале, позиция (120;120), высота 44,
   белая версия. На остальных слайдах логотипа нет; там колонтитул:
   слева капс-название доклада, справа номер.
6. Тёмные слайды (обложка, разделители, финал) — с фирменным свечением:
   эллипс #00ADFF с радиальным затуханием, поворот −32.9°, позиции и стопы
   градиента — в §5 ТЗ. На светлых слайдах свечения нет.
7. Картинки: только приложенные фото Лавки. Никакого стока, AI-иллюстраций,
   3D-клипарта, чужих иконок, теней и градиентов вне ТЗ. Нет фото — воздух.

Порядок работы: сначала покажи три слайда на согласование — обложку, один
контентный с карточками и слайд с цифрами. После моего ок собирай остальные.
