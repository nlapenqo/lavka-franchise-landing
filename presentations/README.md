# Презентации мероприятия (День партнёров)

Презентации спикеров в единой дизайн-системе, унаследованной от финального
лендинга франшизы. Контент взят из агентских PPTX, дизайн — по правилам
[`TZ.md`](TZ.md) (актуальная система v2: статичный HTML, YS Geo
Black/Medium/Regular, 6 кеглей, без колонтитулов). Первая итерация
(`DESIGN-SYSTEM.md`, `TZ-dizajneru.md`, деки в `speakers/`) — архив.
Новые деки — в [`v2/`](v2/).

## Статус
- **Этап 0 (готов):** дизайн-система описана и портирована из `site/` (веб-финал)
  и `concepts/mobile/e-figma.html` (мобильный финал).
- **Этап 1 (идёт):** свёрстаны 3 презентации из 15 — 36 слайдов.
  Остальные 12 добавляются по мере получения файлов от агентства.

## Структура
- `DESIGN-SYSTEM.md` — правила: палитра, типошкала, компоненты, мастер-слайды, чек-лист.
- `_shared/tokens.css` — дизайн-токены слайда 1920×1080.
- `_shared/slides.css` — каркас слайдов, типоклассы, базовые компоненты, @font-face.
- `_shared/blocks.css` — слайдовые компоненты: таймлайны, матрицы, до/после, плитки.
- `_shared/deck.js` + `deck.css` — показ: клавиши, сетка слайдов, полный экран, печать.
- `_shared/glow-defs.html` — блок градиента свечения, вставляется в каждую страницу.
- `_shared/fonts/` — YS Geo / YS Text / YS Text Cond.
- `assets/logo/` — лого-локап (белая версия, для тёмных слайдов).
- `assets/photos/` — фирменные фото, отобранные из исходных PPTX.
- `templates/master.html` — эталон всех типов мастер-слайдов.
- `speakers/NN-familiya/index.html` — презентации.
- `export/` — PDF-выгрузки (1920×1080 на страницу).

## Просмотр
Поднять сервер из корня репозитория и открыть `/presentations/speakers/`.

```bash
python3 -m http.server 8791
```

Внутри презентации: `←` `→` листать, `O` — все слайды сеткой, `F` — во весь
экран, `#7` в адресе — конкретный слайд.

## Экспорт в PDF → Figma
```bash
PORT=8791 tools/export-presentations.sh
```
Кладёт по PDF на каждую презентацию в `export/`. Каждый слайд — отдельная
страница 1920×1080, текст остаётся текстом, свечение — вектором.

## Как добавить презентацию спикера
1. Скопировать соседнюю деку в `speakers/NN-familiya/index.html`.
2. Разложить контент по мастер-слайдам из `templates/master.html` — новых
   кеглей и цветов не вводить, брать компоненты из `blocks.css`.
3. Прогнать проверку вмещаемости (см. §6.1 дизайн-системы) — слайд молча
   обрезает всё, что не влезло в 1080 px.
4. Проверить по чек-листу приёмки в конце `DESIGN-SYSTEM.md`.

## Открытые вопросы
- Финальный формат сдачи: HTML, PDF или PPTX. Сейчас путь — HTML → PDF → Figma →
  плагин в PowerPoint.
- Логотип для светлых слайдов: в проекте есть только белая версия, поэтому
  логотип стоит только на тёмных слайдах. Если нужен на светлых — запросить
  тёмный локап у бренд-команды.
- Исходная презентация «Операции и кухни» помечена [NDA] — уточнить, какие
  цифры можно показывать на общем экране.
- Список остальных 12 спикеров и порядок выступлений — сверить с `partner-day/`.
