# ТЗ · Единая система презентаций Дня партнёров

Актуальная версия от 25.08 (вечер). Заменяет `DESIGN-SYSTEM.md` и
`TZ-dizajneru.md`. Универсально для любой презентации спикера — не только
для уже свёрстанных.

## 0. Задача и принципы

15 спикеров, у каждого презентация. Агентские PPTX годятся только как
источник контента: структуру слайдов и тексты берём оттуда, дизайн — целиком
по этому документу. Главный ориентир дизайна — финальный лендинг франшизы
(`site/`, офлайн-версия `lavka-franchise-offline.html`); презентация должна
выглядеть его продолжением.

Железные принципы (важнее любого пункта ниже):

1. **Тексты не трогаем.** Контент переносится 1-в-1: не переписывать, не
   сокращать, не дописывать. Разрешена только механическая типографика:
   «ёлочки», длинное тире, неразрывные пробелы в числах — без изменения слов.
2. **Чистый слайд.** Никаких колонтитулов, кикеров («09 · Экономика кухни»),
   названий доклада на каждом слайде, подписей по краям и прочего мусора,
   которым грешит нейровёрстка. Единственный сервисный элемент — номер слайда.
3. **Зоны фиксированы.** Заголовок, лид, контент стоят на одних Y-координатах
   на каждом слайде и не зависят от объёма текста. Проверка: листаешь деку —
   ничего не прыгает.
4. **Система, а не украшательство.** Любое решение должно масштабироваться на
   все 15 дек. Новый компонент или тип слайда — сначала вопрос, потом макет.
5. **Одна мысль на слайд.** Заголовок контентного слайда ≤ 2 строк, без
   точки в конце. Display-заголовок обложки, отбивки и финала — до 3 строк.

## 1. Формат

- Слайд **1920 × 1080**, один размер экрана, без адаптива.
- Статичный HTML: слайды идут блоками один за другим, без переходов,
  без анимаций, без JS. Дальше файл разбирается на презентацию вручную.
- Каждая дека — один HTML-файл в `presentations/v2/`, общие стили —
  `presentations/v2/system.css`.

## 2. Шрифт

Только **YS Geo**, три начертания:

| Начертание | Роль |
|---|---|
| **Black** | заголовки, цифры |
| **Medium** | подзаголовки, лиды, подписи, акценты в тексте |
| **Regular** | основной текст, списки |

Запрещены: YS Text, YS Text Web, YS Text Cond, YS Display, Geo Heavy/Bold/Light
и любые другие гарнитуры. Файлы — `presentations/_shared/fonts/`
(используются ровно три TTF).

## 3. Кегли — шесть ступеней

| Ступень | Кегль / интерлиньяж | Начертание | Трекинг | Применение |
|---|---|---|---|---|
| display | 144 / 92% | Black | −2% | заголовок обложки, отбивки, финала; цифра стат-карточки |
| h1 | 96 / 94% | Black | −1% | заголовок слайда; значение в ряду цифр |
| h3 | 40 / 108% | Black | −1% | заголовок карточки |
| lead | 32 / 125% | Medium | 0 | лид, подзаголовок, текст плашки-вывода |
| body | 26 / 135% | Regular | 0 | основной текст, списки |
| small | 20 / 130% | Medium; Regular в плотных таблицах | 0 | подписи, легенды, ячейки матрицы, номер слайда |

Промежуточных и дробных кеглей нет. Мельче 20 на слайде не бывает ничего.
Выделение в заголовке — цветом `#00ADFF` (1–2 слова), не жирностью.
Акцент в наборном тексте — Medium или цвет, не полужирный.

## 4. Палитра

Источник — брендбук франшизы и лендинг.

| Роль | HEX |
|---|---|
| Тёмный фон, весь текст на светлом | `#1B3A6A` |
| Акцент: выделенные слова, цифры, маркеры | `#00ADFF` |
| Плашки, линии, ячейки «Лавка» | `#AAD9FC` |
| Фон светлого слайда | `#F2F7FC` |
| Карточка на светлом | `#EAF3FC` |
| Вторичный текст на светлом | `#5A749B` |
| Вторичный текст на тёмном | `#A7BEE0` |
| Подписи в navy-карточках | `#C0D2EC` |
| Вспомогательный синий (ячейки «партнёр», графики) | `#3E88C5` |
| Горячий акцент — максимум одна деталь на слайд | `#FF6D2F` |

Слайд либо светлый (`#F2F7FC`), либо тёмный (`#1B3A6A`) — третьего фона нет.
Плашка на тёмном слайде — **сплошная белая** `#fff` с текстом `#1B3A6A`, как на
сайте. Полупрозрачных плашек (белый 6–8%, обводки, «стекло») в системе нет.

Запрещено: чёрный и серый текст, лавандовый, «орбиты», liquid glass, любые
полупрозрачные «стеклянные» плашки и обводки вместо заливки, любой блюр
(приём шапки сайта в систему не входит), градиенты кроме фирменного
свечения (§8), любые цвета вне таблицы.

## 5. Сетка и зоны

Сетка: **12 колонок, поля 120 со всех сторон, гуттер 32** (рабочее поле
1680 × 840). Всё по левому краю колонок; по центру — только содержимое
стат-карточки. Отступы кратны 8. Радиусы: карточка 32, ячейка 20, пилюля 999.
Внутренний паддинг карточки 40, плотных ячеек 16.

### Контентный слайд (светлый или тёмный)

| Зона | Y | Спека |
|---|---|---|
| Мини-лого | 120–168 | сердечко в кружке 48 px, правый край поля (x 1752–1800) |
| Заголовок | от 120 | h1, резерв 2 строки, ширина ≤ 10 колонок (не заезжать под лого) |
| Лид (опционально) | от 320 | lead, ≤ 2 строк, ширина ≤ 8 колонок |
| Контент | 440–960 | карточки/списки/таблицы; всегда прижат к верху зоны |
| Плашка-вывод (опц.) | низ на 960, высота 88 | контент над ней заканчивается на 840 |
| Номер слайда | правый низ, в поле | small, x-правый край 1800 |

Зоны не двигаются: нет лида — между заголовком и контентом воздух.
Контент не центрируется по остатку высоты и не «распределяется красиво».

### Обложка (тёмная)

- Полный локап «Яндекс Лавка + Франшиза» — (120; 120), высота 44.
- Справа на той же оси — метка мероприятия капсом (small, +6% трекинга).
- Внизу слева, низ блока на 960: метка доклада (small капсом, `#00ADFF`) →
  заголовок display ≤ 2 строк → лид.
- Фото опционально: колонки 9–12, скругление 32.

### Отбивка раздела (тёмная или фото)

- Полный локап — (120; 120).
- Заголовок display, прижат к низу (низ на 960), ширина ≤ 10 колонок.
- Фото-вариант: full-bleed фото + градиент `#1B3A6A` 92% → 0 слева, текст поверх.
- Больше на слайде ничего нет.

### Финал (тёмный)

- Полный локап — (120; 120).
- Заголовок display + лид (контакты), низ блока на 960.

## 6. Логотип

- **Полный локап** (словомарка + знак + бейдж «Франшиза»,
  `assets/logo/logo-main.svg` + `logo-word-1.svg` + `logo-word-2.svg`) —
  только на обложке, отбивках и финале, всегда в (120; 120). Версия белая,
  поэтому эти слайды всегда тёмные.
- **Мини-знак** — сердечко в голубом кружке (`logo-word-1.svg`, работает на
  светлом и тёмном) — на всех остальных слайдах, 48 px, правый верхний угол
  (1752–1800; 120–168). Если спорит с контентом (full-bleed фото, таблица до
  края) — можно убрать, это единственное исключение.
- Не перекрашивать, не искажать, не поворачивать, без теней. Знак не
  использовать как букву в тексте.

## 7. Компоненты

- **Карточка** — фон `#EAF3FC` (на тёмном — сплошная белая, текст navy), радиус 32,
  паддинг 40; заголовок h3, список body. В сетках 2–4 колонки, гуттер 32,
  равная высота по зоне.
- **Стат-карточка** — navy на светлом слайде, радиус 32, свечение сверху
  из-за края; цифра display белым, подпись h3, пояснение small `#C0D2EC`.
  Содержимое по центру — единственное исключение из левого выравнивания.
- **Ряд цифр** (тёмный слайд, 3–4 значения без карточек) — значение h1
  `#00ADFF`, название body белым, пояснение small `#A7BEE0`.
- **Плашка-вывод** — пилюля на всю ширину поля, высота 88, фон `#EAF3FC`
  (на тёмном — белая); текст lead влево, паддинг 48, акценты цветом.
- **Список** — маркер-круг 10 px `#00ADFF`, текст body, отступ маркера 24.
- **Чип/легенда** — квадрат 20 px радиусом 6 в цвете значения + small.
- **Матрица зон** — шапка колонки small Medium; ячейки small Regular,
  радиус 20, паддинг 16; «Лавка» = `#AAD9FC`/navy, «партнёр» = `#3E88C5`/белый.
- **Пилюля-рубрика** (заголовок половины слайда) — высота 64, паддинг 32,
  фон `#AAD9FC`/navy или `#00ADFF`/белый, текст lead Medium.
- **Линия-разделитель** — 1 px `#AAD9FC` (на тёмном — 22% непрозрачности).
- **Визитка спикера** («Обо мне») — пилюля-метка 48 (`#00ADFF`, small капсом,
  белым), имя (h1 или display; в белой пилюле — 40 или 96, navy), роль small
  капсом, текст lead. Собирается из белых плашек и типографики; семь вариантов
  компоновки — `v2/slide-obo-mne.html`.

Иконки, эмодзи, 3D-клипарт, чужие пиктограммы — запрещены.

## 8. Фирменное свечение (только тёмные слайды)

Тот же приём, что в хиро и блоке цифр лендинга: эллипс с радиальным
градиентом `#00ADFF` (0% → 62% непрозрачности → … → 100% → 0%), поворот
−32.9°. Слоты: A лево-верх (обложка), B право-верх (обложка, второй),
C право-низ (отбивка, финал). Тёмный контентный слайд — один любой.

⚠️ Только **инлайновый `<svg>`** с радиальным градиентом. CSS-градиент или
SVG в `background-image` Chrome растеризует плитками — на тёмном фоне
проступает жёсткая диагональ. На светлых слайдах свечения нет.

## 10. Техреализация и проверка

- `presentations/v2/system.css` — токены, зоны, компоненты; в деках свои
  стили не вводить. @font-face — ровно три файла YS Geo.
- Слайд — `<section class="slide">` фиксированного размера 1920×1080,
  `overflow: hidden`. Слайды подряд в одном файле.
- Слайд молча обрезает всё за 1080 px: перед сдачей прогонять JS-проверку
  нижней границы всех элементов по каждой деке (глазами не поймать).
- Чек-лист приёмки:
  - [ ] листание: заголовки, лого, номер не прыгают
  - [ ] кегли только из §3, начертания только Black/Medium/Regular
  - [ ] всё влево; по центру — только стат-карточки
  - [ ] цвета только из §4; чёрного/серого текста нет
  - [ ] кикеров и колонтитулов нет; из сервисного — только номер слайда
  - [ ] полный локап только на тёмных обложке/отбивках/финале в (120;120);
        мини-знак на остальных в (1752;120)
  - [ ] тексты совпадают с исходником 1-в-1
  - [ ] ничего не вылезает за 1080 (JS-проверка пройдена)

## 11. Процесс

1. **Пилот** — дека «Операции и кухни» в новой системе (`v2/`).
2. Никита комментирует пилот → правки вносятся в этот документ и `system.css`.
3. Остальные 14 дек прогоняются по утверждённой системе. Контент каждой —
   из агентского PPTX (пайплайн разбора описан в auto-memory
   `project-event-presentations`).
